# P3 — Ops layer (watchdog, dumps, backup inclusion, hygiene, final sweep) — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make the agent-ops platform self-healing and recoverable: a health watchdog that restarts failed services, nightly database dumps, inclusion in the off-site backup without leaking secrets, protection from the garbage collector, and a final independent sweep of the whole VPS.

**Architecture:** Two small bash scripts under `/docker/agent-ops/bin/`, each driven by a systemd timer (`agent-ops-health.timer` every 5 minutes, `agentops-dump.timer` nightly at 02:10, before the 02:30 backup). The backup script gains `/docker/agent-ops` as a source with `data/` excluded (dumps included). `gc.sh` gets an explicit guard comment. The final sweep is a read-only critic pass.

**Tech Stack:** bash, systemd timers, `docker compose`, `pg_dumpall`, `sqlite3` (inside containers) or file copies, existing `backup.sh` v5 (md5 `78cee23fbbc657056613134b03045f07`).

**Verified facts:** compose project `agent-ops` (P1/P2) with services `postgres harness coder agentmemory searxng ldr steel`; health endpoints: postgres `pg_isready`, harness `/api/v1/system/health` (3010), coder `/healthz` (3020), agentmemory `/agentmemory/livez` (3111), searxng `/healthz` (8890), ldr `/api/v1/health` (5050), steel `/v1/health` (3030); `backup.sh` SOURCES array and rsync exclude list live in `/root/scripts/vps-maintenance/backup.sh`; `/root/scripts/vps-maintenance/gc.sh` must never touch `/docker/agent-ops`.

### Task 1: Health watchdog

**Files:**
- Create: `/docker/agent-ops/bin/agent-ops-health.sh`, `/etc/systemd/system/agent-ops-health.service`, `/etc/systemd/system/agent-ops-health.timer`, `/docker/agent-ops/state/health.json`

- [ ] **Step 1: Script + timer**

```bash
cat > /tmp/agent-ops-health.sh <<'EOF'
#!/usr/bin/env bash
# agent-ops watchdog — probes every service's health endpoint, restarts a
# service after 3 consecutive failures, writes state/health.json. Idempotent,
# safe to run by hand. Runs every 5 min from agent-ops-health.timer.
set -uo pipefail
cd /docker/agent-ops
STATE=state/health.json; FAILS=state/fail-counts; mkdir -p state; touch "$FAILS"
declare -A PROBE=(
  [postgres]='docker exec agentops-postgres pg_isready -U agentops -d agentops -q'
  [harness]='curl -fsS -m 10 -o /dev/null http://127.0.0.1:3010/api/v1/system/health'
  [coder]='curl -fsS -m 10 -o /dev/null http://127.0.0.1:3020/healthz'
  [agentmemory]='curl -fsS -m 10 -o /dev/null http://127.0.0.1:3111/agentmemory/livez'
  [searxng]='curl -fsS -m 10 -o /dev/null http://127.0.0.1:8890/healthz'
  [ldr]='curl -fsS -m 15 -o /dev/null http://127.0.0.1:5050/api/v1/health'
  [steel]='curl -fsS -m 10 -o /dev/null http://127.0.0.1:3030/v1/health'
)
THRESHOLD=3
now=$(date -u +%Y-%m-%dT%H:%M:%SZ); json="{\"checked_at\":\"$now\",\"services\":{"; first=1; overall=ok
for svc in "${!PROBE[@]}"; do
  count=$(grep -E "^$svc=" "$FAILS" | cut -d= -f2); count=${count:-0}
  if bash -c "${PROBE[$svc]}" >/dev/null 2>&1; then status=ok; count=0
  else count=$((count+1)); status=fail; overall=degraded
    echo "watchdog: $svc health check failed ($count/$THRESHOLD)"
    if [ "$count" -ge "$THRESHOLD" ]; then
      echo "watchdog: restarting $svc after $count consecutive failures"
      docker compose restart "$svc" >/dev/null 2>&1 && status=restarted; count=0
    fi
  fi
  sed -i "/^$svc=/d" "$FAILS"; echo "$svc=$count" >> "$FAILS"
  [ $first = 1 ] || json+=","; first=0
  json+="\"$svc\":{\"status\":\"$status\",\"consecutive_failures\":$count}"
done
json+="},\"overall\":\"$overall\"}"
echo "$json" > "$STATE.tmp" && mv "$STATE.tmp" "$STATE"
echo "watchdog: overall=$overall"
EOF
cat > /tmp/p3-watchdog.sh <<'EOF'
set -euo pipefail
install -m 755 /tmp/agent-ops-health.sh /docker/agent-ops/bin/agent-ops-health.sh
cat > /etc/systemd/system/agent-ops-health.service <<'UNIT'
[Unit]
Description=agent-ops platform health watchdog (restart after 3 consecutive failures)
After=docker.service
Requires=docker.service

[Service]
Type=oneshot
ExecStart=/docker/agent-ops/bin/agent-ops-health.sh
UNIT
cat > /etc/systemd/system/agent-ops-health.timer <<'UNIT'
[Unit]
Description=Run the agent-ops health watchdog every 5 minutes

[Timer]
OnBootSec=3min
OnUnitActiveSec=5min
AccuracySec=30s
Persistent=true

[Install]
WantedBy=timers.target
UNIT
systemctl daemon-reload && systemctl enable --now agent-ops-health.timer
systemctl start agent-ops-health.service; sleep 2
journalctl -u agent-ops-health.service -n 5 --no-pager -o cat
cat /docker/agent-ops/state/health.json; echo
systemctl list-timers --no-pager --no-legend agent-ops-health.timer | awk '{print $NF}'
EOF
scp /tmp/agent-ops-health.sh hos-vps:/tmp/agent-ops-health.sh && scp /tmp/p3-watchdog.sh hos-vps:/tmp/p3-watchdog.sh && ssh hos-vps 'bash /tmp/p3-watchdog.sh'
```
Expected: `watchdog: overall=ok`, `health.json` with all seven services `ok`, timer listed.

### Task 2: Nightly dumps

**Files:**
- Create: `/docker/agent-ops/bin/agentops-dump.sh`, `/etc/systemd/system/agentops-dump.service`, `/etc/systemd/system/agentops-dump.timer`

- [ ] **Step 1: Script + timer + first run**

```bash
cat > /tmp/agentops-dump.sh <<'EOF'
#!/usr/bin/env bash
# Nightly dumps of agent-ops state into /docker/agent-ops/dumps (7-day rotation).
# Runs at 02:10, before backup.sh (02:30) picks the dumps up. Data dirs
# themselves are NOT backed up off-site; these dumps are.
set -euo pipefail
cd /docker/agent-ops
D=dumps; mkdir -p "$D"; TS=$(date -u +%Y%m%dT%H%M%SZ)
docker exec agentops-postgres pg_dumpall -U agentops | gzip > "$D/postgres-$TS.sql.gz"
# SQLite-backed services: copy via the engine's own backup where possible, else a consistent file copy
docker exec agentops-harness sh -c 'ls /data/database.sqlite3 >/dev/null 2>&1 && sqlite3 /data/database.sqlite3 ".backup /data/harness-dump.sqlite3" 2>/dev/null || cp /data/database.sqlite3 /data/harness-dump.sqlite3' 2>/dev/null || true
[ -f data/harness/harness-dump.sqlite3 ] && gzip -c data/harness/harness-dump.sqlite3 > "$D/harness-db-$TS.sqlite3.gz" && rm -f data/harness/harness-dump.sqlite3
tar -czf "$D/harness-repos-$TS.tgz" -C data/harness --exclude=harness-dump.sqlite3 --exclude=database.sqlite3 . 2>/dev/null || true
tar -czf "$D/agentmemory-$TS.tgz" -C data agentmemory 2>/dev/null || true
tar -czf "$D/ldr-$TS.tgz" -C data ldr 2>/dev/null || true
tar -czf "$D/coder-home-$TS.tgz" -C data coder-home 2>/dev/null || true
find "$D" -type f -mtime +7 -delete
du -sh "$D" | cut -f1; ls -1 "$D" | tail -n 6
EOF
cat > /tmp/p3-dump.sh <<'EOF'
set -euo pipefail
install -m 755 /tmp/agentops-dump.sh /docker/agent-ops/bin/agentops-dump.sh
cat > /etc/systemd/system/agentops-dump.service <<'UNIT'
[Unit]
Description=agent-ops nightly state dumps (postgres + sqlite + config dirs)
After=docker.service
Requires=docker.service

[Service]
Type=oneshot
ExecStart=/docker/agent-ops/bin/agentops-dump.sh
Nice=10
UNIT
cat > /etc/systemd/system/agentops-dump.timer <<'UNIT'
[Unit]
Description=agent-ops dumps nightly at 02:10 UTC (before the 02:30 off-site backup)

[Timer]
OnCalendar=*-*-* 02:10:00
Persistent=true

[Install]
WantedBy=timers.target
UNIT
systemctl daemon-reload && systemctl enable --now agentops-dump.timer
systemctl start agentops-dump.service; journalctl -u agentops-dump.service -n 8 --no-pager -o cat
ls -la /docker/agent-ops/dumps | tail -n 7
zcat "$(ls -t /docker/agent-ops/dumps/postgres-*.sql.gz | head -1)" | grep -c "^CREATE DATABASE\|^CREATE ROLE"
EOF
scp /tmp/agentops-dump.sh hos-vps:/tmp/agentops-dump.sh && scp /tmp/p3-dump.sh hos-vps:/tmp/p3-dump.sh && ssh hos-vps 'bash /tmp/p3-dump.sh'
```
Expected: dumps directory lists `postgres-*.sql.gz`, `harness-db-*.sqlite3.gz` (or the repos tarball if Harness stores its DB elsewhere — report the real path), `agentmemory-*.tgz`, `ldr-*.tgz`, `coder-home-*.tgz`; the Postgres dump contains `CREATE ROLE`/`CREATE DATABASE` lines; timer scheduled for 02:10.
